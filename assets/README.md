# IconTiller artwork

## Selected application icon

`icontiller.png` is the original app-tiles concept selected by Kurt: a lifted mint tile within a navy app grid. `icontiller.ico` is the Windows icon derived from it, containing 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel sizes. The application loads the PNG at multiple sizes for title bars and task switching; executable packaging uses the ICO.

## Retained alternate

`icontiller-alternate-tiller.png` is concept two: a stylized mint tiller above three app tiles. Retained at Kurt's request as an alternate design for future reference; it is not the selected application icon and is not included in the executable package.

Both concepts were generated with OpenAI image generation for IconTiller. Original PNGs are preserved without edits.
